# Frontend – RoboKidz Quiz Generator

Next.js React app for creating quizzes and attempting them.

## Setup

```bash
copy .env.example .env
npm install
npm run dev
```

App runs at http://localhost:3000

Make sure the backend is running on http://localhost:8000

## What this UI does

- Form: title, age, lesson text + Generate button
- Loading / error states, button disabled while generating
- List of saved quizzes
- Open a quiz, pick answers, see score at the end
